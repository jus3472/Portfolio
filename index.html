About Me

Hi, I'm Justin! I'm a Computer Science grad from UW–Madison, born and raised in Queens, New York. I got my start teaching kids to code, and since then I've done three software engineering internships at Unibui, U-Haul, and MyFitnessPal, shipping user-facing features. Then a product management internship at H&R Block changed my direction: the questions I enjoyed most weren't about how to build something, but whether we were building the right thing at all.


That's what draws me to product. I love zooming out to think about who we're building for, what problem we're solving, and how we'll know if we made an impact. My favorite part is turning ambiguous, messy problems into concrete ones, and since I've been the engineer in the room, I can stay close to the "how" while owning the "why." Now I'm pursuing APM roles where I get to do both.


Outside of work, I enjoy playing the piano and pursuing my fitness goals at the gym. Both keep me balanced, creative, and focused.


Feel free to explore my portfolio to see my work!

My Projects

Product Feedback Board

A live platform for the core PM problem: collecting user feedback and deciding what to build next. Teams create project boards, gather ideas across 9 categories like feature requests and bug reports, and upvote or downvote submissions, which re-rank by net votes in real time through Firestore listeners. Built in React with Firebase Authentication, owner-scoped Firestore security rules, and a GitHub Actions CI/CD pipeline deploying every merge to GitHub Pages.

Canvas+

A full-stack redesign of the Canvas LMS built with a 6-person team to make coursework easier to navigate and more accessible. It pulls live Canvas API data into a unified dashboard with course progress, to-dos, exams, a threaded inbox, and a due-date calendar. A React front end talks to a Spring Boot and MySQL backend over JWT-secured routes, persisting per-user preferences like dark mode, high contrast, and a dyslexia-friendly font.

Smart Notes

An AI-powered iOS note-taking app that turns spoken conversation into organized, searchable notes. Built with a 4-person team, it records and live-transcribes speech, then uses Gemini 2.5 Flash to generate summaries, speaker-diarized transcripts, action items, and auto-tags. The SwiftUI app syncs notes through Firebase with Core Data persistence, and includes folders, starred notes, and a soft-delete trash with full recovery.
